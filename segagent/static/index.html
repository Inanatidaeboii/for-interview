Upload an image and describe what to label. Gemma 4 plans and decides; SAM 3 segments; the system writes the files. You'll see every step as it happens.

  2. 2SegmentSAM 3 finds every instance and returns ids + facts.
  3. 3DecideGemma reads the facts and the numbered overlay, then picks ids.
  4. 4ExportOverlay image, YOLO boxes & polygons, JSON with masks.
